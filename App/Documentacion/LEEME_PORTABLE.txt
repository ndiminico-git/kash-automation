KA$H v0.691 — Portable para Windows de 64 bits

Extraer el ZIP completo y abrir KASH.App.exe.
Conservar App y .kash-portable junto al ejecutable.
.NET está incluido. Se utiliza Edge WebView2 Runtime, como en v0.690.
No hace falta PowerShell, Visual Studio ni el SDK .NET para ejecutarlo.

ACTUALIZAR LA CARPETA HABITUAL
1. Cerrar KA$H.
2. Extraer el ZIP en otra carpeta.
3. Copiar KASH.App.exe, App y .kash-portable a la carpeta habitual.
4. Reemplazar solo los archivos de aplicación y abrir el mismo EXE.
Conservar Data, Proyectos, .actualizaciones y todos los .kash personales.
El ZIP no contiene datos ni perfiles de prueba. Los accesos directos al
mismo ejecutable siguen siendo válidos.

Desde una prueba de fuente en PowerShell: guardar el proyecto .kash y abrirlo
en el portable. La sesión de .kash-prueba es independiente; conservarla hasta
comprobar que el archivo del proyecto contiene los últimos cambios.

ESTRUCTURA
KASH.App.exe        Aplicación.
App                Interfaz y documentación; necesaria para ejecutar.
.kash-portable     Mantiene el perfil junto al ejecutable.
Data               Se crea al abrir: sesión, preferencias y copias.
Proyectos          Carpeta sugerida, creada al abrir.

Las herramientas de control CSS pertenecen al proyecto de automatización;
no se copian dentro del portable.
